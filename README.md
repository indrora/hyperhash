# hyperhash

A fast, parallel file hashing utility with support for multiple hash algorithms and verification capabilities. Compatible with standard hashing tools like `sha256sum`, `md5sum`, and similar utilities.

## Features

- **Multiple hash algorithms**: Support for MD4, MD5, SHA-1, SHA-2 family, SHA-3 family, BLAKE2B, BLAKE2S, and RIPEMD160
- **Parallel processing**: Multi-threaded hashing for improved performance on multi-core systems
- **Glob pattern support**: Use wildcards to match files (e.g., `*.txt`, `**/*.go`)
- **Hash verification**: Verify existing hash files against computed values
- **Progress tracking**: Visual progress bar during operations
- **Standard compatibility**: Output format compatible with `sha256sum`, `md5sum`, and other standard tools
- **Cross-platform**: Built with Go for portability

## Installation

```bash
go install github.com/indrora/hyperhash@latest
```

Or clone and build locally:

```bash
git clone https://github.com/indrora/hyperhash.git
cd hyperhash
go build
```

## Usage

### Basic Hashing

Generate hashes for files matching a pattern:

```bash
hyperhash [flags] <glob-pattern>...
```

Examples:

```bash
# Hash all files in current directory
hyperhash *

# Hash all Go files recursively
hyperhash "**/*.go"

# Hash specific files
hyperhash file1.txt file2.txt

# Use MD5 instead of default SHA256
hyperhash --hash-type md5 *.txt
```

### Hash Verification

Verify previously computed hashes:

```bash
hyperhash --verify checksums.txt
```

The verification file should contain lines in the format:
```
<hash> <filepath>
```

This format is compatible with files generated by `sha256sum`, `md5sum`, `sha512sum`, and similar tools.

### Options

- `--hash-type <algorithm>`: Hash algorithm to use (default: sha256)
- `--verify`: Verify mode - check files against existing hash file
- `--workers <n>`: Number of worker threads (default: number of CPU cores)
- `--help`, `-h`: Show help and list available hash algorithms

### Supported Hash Algorithms

- **MD4**, **MD5**
- **SHA-1**
- **SHA-224**, **SHA-256**, **SHA-384**, **SHA-512**
- **SHA3-224**, **SHA3-256**, **SHA3-384**, **SHA3-512**
- **BLAKE2B-256**, **BLAKE2B-384**, **BLAKE2B-512**
- **BLAKE2S-256**
- **RIPEMD160**

Algorithm names are case-insensitive.

## Examples

### Generate SHA256 checksums for all files (compatible with sha256sum)
```bash
hyperhash "**/*" > checksums.sha256
sha256sum --check checksums.sha256  # Verify with standard tool
```

### Verify checksums
```bash
hyperhash --verify checksums.sha256
```

### Hash with different algorithm and custom worker count
```bash
hyperhash --hash-type blake2b-256 --workers 8 "*.bin"
```

### Compatibility with standard tools
```bash
# These are equivalent:
sha256sum *.txt > hashes.txt
hyperhash --hash-type sha256 "*.txt" > hashes.txt

# Verification works both ways:
hyperhash --verify hashes.txt
sha256sum --check hashes.txt
```

### Output format

**Hash mode** output (compatible with `*sum` tools):
```
a1b2c3d4e5f6...  path/to/file1.txt
b2c3d4e5f6a7...  path/to/file2.txt
```

**Verify mode** output:
```
path/to/file1.txt: OK
path/to/file2.txt: MISMATCH
```

## Performance

hyperhash uses parallel processing to maximize throughput on multi-core systems. The number of worker goroutines defaults to the number of CPU cores but can be customized with the `--workers` flag.
